# ASMMA Production – Portfolio Website

A single-file static website (`index.html`). All images are embedded, so there is nothing else to upload.

## Put it online with GitHub Pages
1. Create a new repository on GitHub (for example `asmma-website`).
2. Upload `index.html` and `README.md` to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select the `main` branch and the `/ (root)` folder, then click **Save**.
5. After a minute your site will be live at `https://YOUR-USERNAME.github.io/asmma-website/`.
